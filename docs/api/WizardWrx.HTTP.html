JSON_Deserialized_Object

Instances of this class provide a lightweight, schema-aware façade over a JSON payload. The class optionally sanitizes the input, validates required fields, and exposes a minimal set of typed accessors so callers can retrieve field values without depending directly on JSON.NET, working with JToken instances, or needing to expend the effort to parse the JSON into a strongly-typed model when only a few fields are needed.
