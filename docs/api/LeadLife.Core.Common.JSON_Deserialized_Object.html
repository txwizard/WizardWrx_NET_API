Parameters
Type Name Description
System.Boolean pfRequireNonEmptyValues

This flag indicates whether to enforce that the required fields have non- empty values. If true, then any required field that is either null or a string consisting only of whitespace will be considered missing.
Returns
Type Description
List<System.String>

This method returns a list of missing required fields. If the JSON document is invalid, the list will contain a single entry "Invalid JSON". If all required fields are present (and non-empty when required), the returned list is empty.
