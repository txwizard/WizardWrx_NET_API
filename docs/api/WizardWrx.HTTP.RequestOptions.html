RequestOptions.OAuthTokenGetter ptokenGetter

The delegate that retrieves OAuth Bearer tokens for inclusion in the Authorization header of HTTP requests is optional; if no delegate is provided, requests proceed without Authorization headers.
System.String pstrInitialOAuthToken

This optional parameter allows the caller to supply an initial OAuth token that the class caches for future use. If this parameter is null and ptokenGetter is not null, the class attempts to obtain a token the first time the property value is queried.
System.String pstrContentType

This optional string parameter sets the Content-Type HTTP header value for requests made using the associated HTTP engine. If this parameter is null, the Content-Type header is omitted from requests By specifying a value for this parameter, developers can indicate the media type of the request body, ensuring that the server can correctly interpret the data being sent. This allows for greater flexibility in handling different types of request payloads and can help prevent issues related to content negotiation between the client and server.
System.String pstrAcceptHeaderValue

When specified, thiis string represents the value to include as the Accept HTTP header value. By default, the null value, "/", is added.
System.String pstrAcceptEncodingValue

When specified, this string represents the value to include as the Accept-Encoding HTTP header value. By default, this value is null, and is, therefore, omitted.
System.String pstrCacheControlValue

When specified, this string represents the value to include as the Cache-Control HTTP header value. The default value is "no-cache".
System.Int32 pintRetryLimit

This integer specifies the maximum number of times to retry a request that fails due to a transient error, such as a network issue or a server error. The default value is 10, which means that the HTTP engine will attempt to retry a failed request up to 10 times before giving up and returning an error to the caller. This parameter allows developers to control the behavior of the HTTP engine in the face of transient errors, providing a mechanism for automatically retrying requests that may succeed on subsequent attempts.
System.Int32 pintRetryDelay

This integer specifies the delay, in seconds, between retry attempts for a request that fails due to a transient error. The default value is 10, which means that the HTTP engine will wait for 10 seconds before attempting to retry a failed request. This parameter allows developers to control the timing of retry attempts, providing a mechanism for introducing a delay between retries to avoid overwhelming the server or network with rapid-fire requests. By adjusting the retry delay, developers can optimize the balance between retrying failed requests and avoiding excessive delays in the overall request processing.
System.Int32 pintTimeout

This integer specifies the timeout in seconds for HTTP requests. The default value is 120, which means that the HTTP engine will wait for 120 seconds before timing out a request and returning an error to the caller. This parameter allows developers to control the maximum amount of time that the HTTP engine will wait for a response before giving up and returning an error. By adjusting the timeout value, developers can optimize the balance between allowing sufficient time for requests to complete and avoiding excessive delays in the overall request processing. Since it is generally inadvisable to set the timeout to an infinite value, as this can lead to requests hanging indefinitely and potentially causing issues with resource management and application performance, this library does not support setting an infinite timeout and instead enforces a finite timeout value to ensure that requests are handled in a timely manner.
RequestOptions.HttpEngineLogCallback pdiLogCallback

This delegate is called to log messages from the HTTP engine. It is optional; if no delegate is provided, no logging occurs.

If logging is enabled, the delegate is expected to handle the log messages appropriately, such as by writing them to a log file, displaying them in a console, or sending them to a logging service. The additional parameters provide context about the source of the log message, including the member name, source file path, and line number where the log message was generated. This information can be useful for debugging and tracing the flow of execution in the HTTP engine, allowing developers to identify the specific location in the code where the log message originated. The use of CallerMemberName, Caller FilePath, and CallerLineNumber attributes allows the HTTP engine to automatically capture this contextual information without requiring the caller to explicitly provide it, making it easier to implement logging throughout the codebase. Overall, this delegate provides a flexible and powerful mechanism for logging messages from the HTTP engine while also capturing important contextual information for debugging purposes.

Timeout

This integer specifies the Timeout in seconds.

The default value is 100,000 milliseconds (100 seconds). The documentation for HttpClient.Timeout states that the default value is 100 seconds, and that the property is of type TimeSpan.

When unitialized, the Timeout property behaves as if it had been set to the default value of 100 seconds, which is equivalent to 100,000 milliseconds.

Though the Timeout property supports setting an infinite timeout by setting the property value to InfiniteTimeSpan, we do not support that feature in this library, as it is generally not advisable to allow requests to hang indefinitely.
