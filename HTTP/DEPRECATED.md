## **WizardWrx.HTTP — Deprecated and Frozen**

The **WizardWrx.HTTP** library is no longer under active development.

This project has been **formally deprecated** and its source code is preserved
here in its final, frozen state for the benefit of existing consumers.

### Why This Project Is Deprecated

The HTTP request engine originally lived in the WizardWrx constellation as a
matter of convenience during its early development. Its long‑term home is now
**outside** the WizardWrx ecosystem, and future evolution of the engine will
occur in a private downstream project.

### What This Means for Consumers

- The code in this directory is **stable**, **supported as‑is**, and will remain
  available indefinitely.
- No new features, enhancements, or API changes will be made.
- No further NuGet releases of `WizardWrx.HTTP` are planned.
- Existing applications depending on this package may continue to do so safely.

### Versioning and Maintenance

The final published NuGet package has been marked as **deprecated** on nuget.org.

This repository retains the complete source code for archival and reference
purposes.

If you are an existing consumer and require long‑term maintenance, you may fork
this directory under your own version control and evolve it independently.
